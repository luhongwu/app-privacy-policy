## 3. お客様が提供する写真とその利用

### 3.1 写真の取得元

ヘアスタイルのプレビューを生成するため、お客様は次の方法で写真を提供できます:

- デバイスの**カメラ**で写真を撮影する;
- デバイスの**フォトライブラリ**から既存の写真を選択する。

### 3.2 写真の利用目的

お客様が選択した写真は、以下の目的にのみ使用されます:

1. お客様のデバイス上でのローカルな形式検証および圧縮処理;
2. **HTTPS 暗号化通信**により第三者の AI 画像処理 API へアップロードし、ヘアスタイルのプレビュー画像を生成するため;
3. 生成された画像は、お客様の確認後にお客様自身の操作によってデバイスのフォトライブラリに保存されるか、本アプリのローカル履歴に保持されます。

サービスの安全確保、濫用防止、障害対応、および必要な内部の品質・コンプライアンス審査のため、当社は写真に対して技術的な処理（異常な呼び出しの検出、違法コンテンツの自動検出、解像度・形式の検証など）を行う場合がありますが、これによってお客様を識別することはありません。

### 3.3 当社が行わないこと

- お客様の写真はヘアスタイルプレビューの生成に必要な間のみ取り扱われ、それ以外に当社が保持することはありません;
- 当社はお客様の写真を広告、プロファイリング、または AI モデルの学習に**使用しません**（第三者 AI 提供者による処理については第 7 条に記載）;
- 上記の第三者の AI 処理 API および第 7 条に記載のサービス提供者を除き、お客様の写真が他の者へ送信されることは**ありません**;
- アップロードされる写真には顔情報が含まれる場合があり、これは要配慮個人情報にあたります。アップロードにより、お客様はヘアスタイルプレビューの生成および関連するセキュリティ・コンプライアンス処理のための利用について**個別の同意**を与えたものとみなされます。**この同意はいつでも第 13 条の連絡窓口を通じて撤回できます。撤回後は写真処理機能をご利用いただけなくなり、既に消費されたクォータおよび既に支払われた料金は撤回を理由として返金されません。**

## 5. デバイスの権限

本アプリは、中核機能に必要な権限のみを要求します:

| プラットフォーム | 権限 | 目的 |
|------------------|------|------|
| Android | INTERNET | ヘアスタイル生成のための AI API の呼び出し、および生成画像のダウンロード |
| Android | CAMERA | ヘアスタイル生成のための写真撮影（写真撮影をタップしたときのみ発動します） |
| Android | READ_MEDIA_IMAGES（Android 13 以降） / READ_EXTERNAL_STORAGE（Android 12 以前） | ヘアスタイル生成のためのフォトライブラリからの写真選択。Android 14 以降では、選択した写真のみへのアクセス（READ_MEDIA_VISUAL_USER_SELECTED）に対応しています |
| Android | POST_NOTIFICATIONS（Android 13 以降） | 非同期生成完了時のシステム通知の送信（お客様の許可が必要です） |
| iOS | NSCameraUsageDescription | ヘアスタイル生成のための写真撮影 |
| iOS | NSPhotoLibraryUsageDescription | ヘアスタイル生成のためのフォトライブラリからの写真選択 |
| iOS | NSPhotoLibraryAddUsageDescription | 保存を選択した生成画像のシステムフォトライブラリへの書き込み |

注記: 本アプリは `WRITE_EXTERNAL_STORAGE` を**要求しなくなりました**。生成画像はシステムのメディアライブラリ API（MediaStore / PhotoKit）を通じて保存され、追加のストレージ権限は不要です。すべての権限は、お客様が該当機能を能動的に利用したときにのみ発動し、バックグラウンドで呼び出されることはありません。**これらの権限はいつでも拒否または取り消すことができます。拒否または取り消し後は該当機能が利用できなくなる場合がありますが、他の機能には影響せず、また当社が当該機能を提供する義務に違反するものでもありません。**
