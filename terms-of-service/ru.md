## 2. Описание сервиса

### 2.1 Содержание сервиса

Приложение представляет собой **инструмент предварительного просмотра причёсок с помощью ИИ**. Вы загружаете своё фото, выбираете причёску и цвет волос, а Приложение создаёт изображения предварительного просмотра причёски через API обработки изображений ИИ третьей стороны. Основные функции включают:

- Создание фотографии или выбор её из фотобиблиотеки;
- Более 60 причёсок (категории для мужчин/женщин) и 22 цвета волос на выбор;
- Асинхронная генерация ИИ изображений предварительного просмотра причёсок;
- Сохранение сгенерированных результатов в системную фотобиблиотеку и управление записями истории;
- Многоязычный интерфейс (включая раскладку справа налево (RTL)), тёмный/светлый режим и несколько цветовых тем.

### 2.2 Характер сервиса

**Приложение предоставляется исключительно в развлекательных и справочных целях.** Сгенерированные предварительные просмотры причёсок являются симуляциями ИИ и не представляют собой профессиональную консультацию по стилю причёски и не отражают реального результата стрижки или окрашивания. Пожалуйста, проконсультируйтесь со специалистом перед принятием реального решения о стиле.

## 3. Ограничения использования

### 3.1 Политика добросовестного использования

Каждая генерация ИИ в этом Приложении вызывает платный API ИИ третьей стороны с оплатой за запрос, и Разработчик несёт реальные расходы по каждому запросу на генерацию. Эта политика призвана защитить обычный опыт использования подавляющего большинства пользователей и одновременно предотвратить злоупотребление API или аномально частое использование. **Мы вправе выявлять и обрабатывать аномальное использование на основе объективных, разумных и недискриминационных критериев, включая, помимо прочего, ограничение частоты вызовов, приостановку сервиса или прекращение вашего использования Приложения.**

### 3.2 Политика сервиса

- **Квота подписки**: количество генераций, доступных подписчику в каждом периоде, зависит от квоты его **тарифа подписки**. **Эта квота, её цикл сброса и правила потребления определяются настоящими Условиями** и могут быть просмотрены в отображении квоты Приложения; тарифы разной длительности имеют разные квоты;
- **Периодический сброс, без переноса**: квота пересчитывается в начале каждого периода. Неиспользованная квота предыдущего периода **не переносится**, не конвертируется в денежные средства и не возвращается;
- **Расходуется при одобрении, не возвращается при сбое**: квота расходуется, когда ваш запрос на генерацию **одобрен (проходит предварительную проверку)**, а не при успешной генерации.
